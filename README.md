# PRIVACY-PRESERVING FEDERATED LEARNING FRAMEWORK FOR MULTI-HOSPITAL MEDICAL DATA ANALYSIS

## CKD Case Study

This academic prototype demonstrates simulated multi-hospital federated learning, hospital-wise missing-feature settings, experimental adaptive noise, FedAvg result visualizations, CKD prediction using a saved global model, membership-inference evaluation, and report downloads.

**Important:** The hospitals are simulated from public datasets. The dashboard is an academic demonstration, not a medical diagnostic tool. The experimental noise mapping does not establish a formal differential-privacy guarantee. Do not enter identifiable patient information.
